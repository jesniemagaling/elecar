# Elecar – HTML & CSS Project

**Elecar** is a static webpage built using only **HTML** and **CSS**.  
This project was created as an exercise in mastering CSS—exploring layout techniques, selectors, responsiveness, and handcrafted design details without any frameworks.

---

## Overview

Elecar began as a way to apply and deepen CSS skills after learning HTML and CSS fundamentals.  
It demonstrates:

- Effective layout structuring with semantic HTML
- Custom styling techniques like flexbox, grid, gradients, or animations
- Responsive design across devices without utilities or libraries

This is a starter project focused on aesthetics and CSS control.

---

## Key Features

- Clean, semantic HTML markup  
- Custom CSS for typography, spacing, colors, and layout  
- Responsive design  
- Optional interactive effects (hover states, transitions, animations)

---

## Tech Stack

- **HTML5** – Structured content and semantics  
- **CSS** – Manual styling—no Tailwind, no preprocessor, no frameworks
